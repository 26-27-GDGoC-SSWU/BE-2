# BE-2

GDGoC SSWU 26-27 BE-2 스터디 실습 코드 저장소입니다.

## 폴더 구조

멤버별 브랜치를 생성하고, 그 안에 본인 이름 폴더 → 주차별 폴더 순으로 코드를 올립니다.

```
BE-2
└── (멤버 브랜치)
    └── (멤버 이름)
        ├── week01
        ├── week02
        └── ...
```

## 규칙

- 스터디 정리 일지는 노션에 작성합니다.
- 실습 코드는 본인 브랜치의 본인 이름 폴더 아래, 주차별 폴더에 커밋합니다.
- 커밋 메시지는 아래 형식을 따릅니다.

  ```
  feat: 새로운 기능 추가
  fix: 버그 수정
  docs: 문서 수정
  chore: 기타 잡일성 작업
  ```

## 시작하기

```bash
git clone https://github.com/26-27-GDGoC-SSWU/BE-2.git
cd BE-2
git checkout -b 본인이름
mkdir -p 본인이름/week01
```
